==================================================
 SINGLY vs DOUBLY LINKED LIST
==================================================
Feature                 Singly            Doubly
--------------------------------------------------
Pointers per node       1 (next)          2 (prev, next)
Memory per node         Less              More
Traversal direction     Forward only      Forward + Backward
Insert at beginning     O(1)              O(1)
Insert at end           O(n) (no tail)    O(1) (with tail)
Delete from end         O(n)              O(1) (with tail)
Delete a given node     Needs prev node   Direct (has prev)
Reverse                 O(n), O(1) space  O(n), O(1) space
Implementation          Simpler           More pointer updates
--------------------------------------------------
Sizes on this machine: SNode = 16 bytes, DNode = 24 bytes

--- Live demo: same data 40, 10, 30, 20, 50 in both lists ---

Singly (can go forward only):
  40 -> 10 -> 30 -> 20 -> 50 -> NULL
Doubly forward:
  NULL <- 40 <-> 10 <-> 30 <-> 20 <-> 50 -> NULL
Doubly backward:
  NULL <- 50 <-> 20 <-> 30 <-> 10 <-> 40 -> NULL

After sort + reverse:
  Singly: 50 -> 40 -> 30 -> 20 -> 10 -> NULL
  Doubly forward : NULL <- 50 <-> 40 <-> 30 <-> 20 <-> 10 -> NULL
  Doubly backward: NULL <- 10 <-> 20 <-> 30 <-> 40 <-> 50 -> NULL
